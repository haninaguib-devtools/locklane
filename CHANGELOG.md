# Changelog

Curated notes for each locklane release, newest first — one `## v<version>` section per
release, generated by `scripts/generate-release-notes.sh` from the squash commits since
the previous release tag and grouped by each change's issue classification label
(`docs/architecture/releasing.md` § Release notes). The body of the `v<version>` GitHub
Release is this file's matching section, extracted verbatim at cut time. The changelog
starts with the first release cut after #464 landed; earlier releases have no section
here.
