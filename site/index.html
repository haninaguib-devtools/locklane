Install

From zero to your first lane.

One command downloads the latest Locklane build and walks you through the local port, allowed origins, and first admin login.

Terminal macOS · Linux
$ curl -fsSL https://raw.githubusercontent.com/haninaguib-devtools/locklane/main/install.sh | bash

Requires Java 21+ and the authenticated GitHub CLI while the repository is private. The installer writes only to ~/.locklane.

Why Locklane

The browser becomes the cockpit.
Your repository stays the truth.

Agent sessions are easy to start and surprisingly hard to keep oriented. Locklane gives every task a visible home: its issue, branch, worktree, consoles, and the checks that decide what happens next.

Nothing hides in a queue. You can see the work, enter the terminal, and take over at any point.

How it works

One lane from issue to merge.

Locklane keeps the working environment and the delivery record close together. Your existing tools keep doing their jobs.

  1. 1

    Add a repository

    Connect a GitHub project. Locklane checks it out into a managed work area and reads its issue tree.

    git clone → workarea
  2. 2

    Open an issue lane

    Create an isolated worktree from the task, then start Codex, Claude, or a plain shell inside it.

    issue → worktree → PTY
  3. 3

    Stay through the gate

    Watch checks, review state, and agent attention in one place. The human still decides when work moves.

    checks → review → merge

Local by design

Your code stays where the tools are.

Locklane is a self-hosted Spring Boot engine with an Angular PWA and SQLite state. It orchestrates normal git worktrees and real terminal processes on your machine—then makes them reachable from the browser.
